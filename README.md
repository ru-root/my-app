# Socks Tunnel

Маленький Android-клиент для сервера 3proxy за stunnel.

Что делает:
- подключается к ruroot.ru:9443 по TLS (сертификат проверяется по системному хранилищу Android);
- авторизуется на 3proxy по логину/паролю (SOCKS5, RFC 1929);
- поднимает локальный SOCKS5 на 127.0.0.1:5557 (по желанию — с требованием логина/пароля);
- работает в фоне как foreground-сервис, переподключается при обрыве;
- без VPN-сервиса: трафик телефона целиком не перехватывается, работают только приложения,
  в которых явно указан прокси socks5://127.0.0.1:5557.

## Сборка через GitHub
1. Создайте репозиторий на GitHub.
2. Загрузите в него все файлы этого архива (распакуйте ZIP и загрузите содержимое: папки .github, app и файлы build.gradle, settings.gradle, gradle.properties, README.md).
3. Дождитесь окончания Actions — во вкладке Actions появится артефакт SocksTunnel-debug с app-debug.apk.
4. Скачайте APK, установите на телефон (разрешите установку из неизвестных источников).

## Использование
1. Введите сервер, порт, логин и пароль 3proxy.
2. При необходимости включите «Требовать логин/пароль на локальном SOCKS5» — тогда приложения должны указать те же креды в настройках прокси.
3. Нажмите «Подключить», затем в нужных приложениях укажите socks5://127.0.0.1:5557.

## Настройка 3proxy на сервере
На стороне ruroot.ru 3proxy должен слушать SOCKS5 с авторизацией (флаг -а1 или users),
а stunnel — терминировать TLS на порту 9443 и передавать 3proxy в виде обычного SOCKS5.
