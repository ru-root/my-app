Что сделать

    Распакуйте ZIP и загрузите содержимое в новый репозиторий GitHub (папку .github тоже — там workflow).
    GitHub сам соберёт APK, во вкладке Actions > артефакт SocksTunnel-debug будет app-debug.apk.
    Установите APK, разрешив установку из неизвестных источников.
    
    
    
    
    
    
    
    
    
    Как это выглядит на практике:

    Создайте репозиторий на GitHub (галочку «Add a README» можно не ставить).
    Загрузите файлы из ZIP — через веб-интерфейс это «uploading an existing file», можно перетащить всё сразу.
    Через минуту-две во вкладке Actions появится запущенная сборка (workflow уже лежит в .github/workflows/build.yml).
    Когда сборка позеленеет — откройте её, внизу будет артефакт SocksTunnel-debug с готовым app-debug.apk.

Единственное, что может понадобиться — один раз нажать «Enable workflows», если Actions в новом репозитории отключены по умолчанию.

Если что-то на этапе GitHub пойдёт не так — пришлите текст ошибки из Actions, я разберу и поправлю файлы.
